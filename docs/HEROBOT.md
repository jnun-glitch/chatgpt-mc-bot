# HeroBot Integration

TheoBot uses the currently published HeroBot player-control surface.

Used commands:
- playerspawn
- player ... move forward
- player ... move backward
- player ... move left
- player ... move right
- player ... move
- player ... look
- player ... look upon
- player ... look at
- player ... look random
- player ... jump once
- player ... autojump true/false
- player ... sprint/unsprint
- player ... path entity
- player ... path pos
- player ... path stop
- player ... disconnect

The datapack does not reimplement fake-player internals.
