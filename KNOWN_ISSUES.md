# Known Issues

- Live Minecraft execution has not been performed here.
- Target acquisition currently means nearest eligible non-bot player within 32 blocks.
- There is no line-of-sight/team-priority perception layer yet.
- The menu is a command helper, not an inventory GUI.
- HeroBot command syntax must stay compatible with docs/HEROBOT.md.
- The larger combat/weapon layer is intentionally not included in this repository state.
